# Jabber AI Assistant

Персональный AI-ассистент, который подключается к существующему браузеру с открытыми вкладками Jabber и ChatGPT, перехватывает входящие XMPP-сообщения и отвечает на них через ChatGPT.

## 🚀 Быстрый старт
